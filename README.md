# Xiaoyue (Lucy) Liu

Personal academic website for Xiaoyue (Lucy) Liu.

Intended site URL: https://lucyxx1177.github.io/

- Personal information and experience: `_data/profile.yml`
- Publications: `_publications/`
- CV: `assets/files/Xiaoyue_Liu_PHD_27Fall_Resume.pdf`
- Styling: `assets/css/global.css`

## Local preview

With Ruby 3.3 and Bundler installed:

```sh
bundle install
bundle exec jekyll serve
```

## Deployment

Use the repository name `LucyXX1177.github.io` and select **Settings > Pages > Source > GitHub Actions**.
The included workflow builds and deploys changes pushed to `main`.
